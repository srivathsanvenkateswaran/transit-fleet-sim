# transit-fleet-sim

A simulated bus fleet for Bengaluru, serving live vehicle positions over
GTFS-Realtime and a fleet registry that maps a Bus Identification Number to a
number plate and the duty it is running.

It exists so a transit app and a ticketing service can be built and demonstrated
against live tracking without real vehicles, real devices, or a real operator
feed.

Specification in progress. See SPEC.md.
